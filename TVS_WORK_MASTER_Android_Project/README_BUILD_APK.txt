TVS WORK MASTER - ANDROID APP PROJECT

This project wraps the offline TVS WORK MASTER app in a simple Android WebView. It does not require internet permission and loads the app from the phone itself.

HOW TO BUILD THE APK (using your laptop):
1. Install Android Studio from the official Android developer website: https://developer.android.com/studio
2. Extract this ZIP file.
3. Open Android Studio -> Open -> choose the extracted TVS_WORK_MASTER_Android_Project folder.
4. Allow Android Studio to sync/download the Android Gradle Plugin and Android SDK components if prompted. Internet is needed for this first build.
5. Select Build -> Build Bundle(s) / APK(s) -> Build APK(s).
6. When it finishes, click "locate" in the notification. The APK will be in app/build/outputs/apk/debug/app-debug.apk.
7. Transfer app-debug.apk to your Android phone, tap it, and allow installation from that source if Android asks.

IMPORTANT:
- This ZIP is an Android Studio project, NOT the compiled APK itself.
- I could not compile a genuine APK in this environment because Android SDK/Gradle build tools are not installed here.
- Starter prices in the app should be checked and edited to match your dealership's current prices and labour charges.
- Your app data is stored locally on the phone. Keep backups using the app's backup/export feature.
